ANALYSES ANONYMISEES — "RAG seul vs RAG+recherche web : meilleure inference ou pollution/dissonance ?"

A1 : Le vrai probleme = la coherence des sources et le mecanisme de fusion, pas la source. Le web apporte bruit (fake-news) sans filtre de credibilite ; le RAG seul est controle ; un mauvais merging amplifie les contradictions. Falsifiable : RAG+web avec filtrage credibilite > RAG seul d'au moins 5% en F1, sinon la combinaison ne se justifie pas.

A2 : RAG+web AVEC validation stricte des sources : donnees temps reel impossibles au RAG statique, +38% de pertinence post-2023, scoring de domaine + verification croisee limite la fake-news a <4%. Sans validation, erreurs 3,5x le RAG seul.

A3 : Ca depend de la fiabilite des sources : corpus elargi et actualise corrige les lacunes, les moteurs filtrent par pertinence, mais expose a du polarise/dissonant. Falsifiable : >30% de reponses incoherentes avec web actif = deterioration.

A4 : RAG SEUL superieur : ancrage documentaire certifie, tracabilite totale, stabilite. Le web est un facteur de divergence selon la requete. Falsifiable : sur 100 requetes techniques, le taux de reponses incorrectes est >=15% superieur pour RAG+web.
